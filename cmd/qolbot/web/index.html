What this is

Qolbot runs Diablo II characters as helpers, two ways. You play: you host a TCP/IP game, check the bots that should join, press Start, and they walk in and follow you, fight beside you and look after their own characters. You do not play: you pick a bot to lead and an objective, farming the locations you choose or playing the quests, and the leader hosts the game and does the work while the others follow. Either way nobody has to sit at them.

Where it comes from

The brains are Kolbot, the long-standing set of Diablo II bot scripts by Kolton and its community, running inside D2BS, the library that lets those scripts see and control the game. Normally a program called D2Bot starts the games and injects D2BS, but it does not run under Wine. Qolbot replaces that part: it launches the games, injects D2BS and passes messages between the game and this page. The Kolbot and D2BS code is kept and extended, not rewritten.

An older build, on purpose

This is based on an older Kolbot and D2BS build made for Diablo II version 1.13 (LoD, the final classic patch), the version PlugY runs on. Newer Kolbot versions target other game builds and do not fit this setup, so the scripts here are an older generation with fixes and new features added. Those additions are what let the bots follow you, farm, play the quests and look after their own gear, points and saving.

What runs where

On Linux and macOS the games run under Wine in a private prefix (~/.qolbot_wine_prefix), so they never touch your own Wine setup, and on Linux they use a hidden display so no windows appear. The bots launch from your own game folder: nothing is copied or linked, and Qolbot never changes your game files. It only checks that PlugY.ini and BaseMod.ini have the World Event off (it crashes bots) and warns if not. Logs are in logs/ and can be cleared from the Bots tab.

Bots cannot start yet. Set the path to Game.exe on the Settings tab first.
